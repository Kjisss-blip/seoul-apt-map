# 서울 아파트 시황 지도

서울 25개 구의 아파트 시황을 보는 인터랙티브 지도입니다. 파일 하나(`index.html`)로 동작합니다.

## 레이어
1. 구별 3.3㎡당 매매 중위가 (3개월 이동 중위값, 전용면적 기준)
2. 중위가 변화율 (전년동월비·전월대비)
3. 정말 올랐나 — 단순 중위 vs 품질 보정 지수 vs 한국부동산원 지수, 신축 거래 비중 변화
4. 전세가율(단지 단위, 6개월 창)과 월세 비중

## 읽을 때 주의
- 단가는 **전용면적** 기준이라 부동산 앱의 평당가(공급면적 기준)보다 높게 보입니다.
- 회색은 표본 부족 또는 신고기한(계약 후 30일)이 지나지 않아 값이 덜 모인 달입니다. 최근 달 값은 바뀔 수 있습니다.
- 중위가 변화율은 어떤 단지·면적이 팔렸는지에 따라 움직이므로 곧 집값 변화는 아닙니다.
- 투자 판단의 근거로 쓰지 마세요. 참고용 통계입니다.

## 출처
- 아파트 매매·전월세 실거래가: 국토교통부 실거래가 공개자료(공공데이터포털)
- 매매가격지수: 한국부동산원 R-ONE
- 구 경계: 통계청(KOSTAT) 센서스용 행정구역경계 2013 (southkorea/seoul-maps)
- 배경 지도: Esri, HERE, Garmin, OpenStreetMap 기여자
- 지도 라이브러리: Leaflet (BSD-2-Clause)
